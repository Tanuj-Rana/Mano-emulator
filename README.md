# Mano 16-Bit Emulator

A C-based instruction-level virtual machine inspired by the Morris Mano Basic Computer architecture.

This project simulates a custom 16-bit CPU using a Fetch-Decode-Execute pipeline with an 8-bit byte-addressable memory model and support for memory-reference, register-reference, and I/O instructions.

## 🔗 Toolchain Integration

This emulator acts as the execution backend of the **Bare-Metal-Core** ecosystem. It is designed to load and execute compiled binary images (`.bin`) generated by the custom Mano assembler.

To compile your assembly code into a compatible binary for this virtual machine, please use the official companion assembler repository:
* **[View the Mano-Machine Assembler Toolchain Here](https://github.com/AnshuNegi2006/Mano-Machine-Assembler/tree/88ab7f6551228c4f04ffb1a54d9468c71c3ecc41)**

## ✨ Features

- 16-bit instruction execution
- Fetch–Decode–Execute cycle
- Byte-addressable memory model
- Memory-reference instructions
- Register-reference instructions
- I/O instructions
- Branching and control flow
- Custom opcode support
